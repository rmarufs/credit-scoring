# Credit Scoring

Проект по кредитному скорингу: модель оценивает вероятность дефолта заёмщика, предсказания отдаёт через API на FastAPI, всё упаковано в Docker.

## Данные

### Источник
Kaggle: [Credit Risk Dataset](https://www.kaggle.com/datasets/laotse/credit-risk-dataset).
Файл лежит в `data/raw/` и в git не попадает.

### Назначение
Бинарная классификация: оценка вероятности дефолта по кредиту.

### Размер
32 581 строка, 12 столбцов (11 признаков и целевая переменная). Используется весь датасет, без сэмплирования.

### Целевая переменная
`loan_status`: 1 означает дефолт, 0 означает кредит погашен.
Доля дефолтов: 21,8%, то есть дисбаланс умеренный.

### Признаки

| Столбец | Тип | Описание | Диапазон |
|---|---|---|---|
| `person_age` | число | Возраст заёмщика | 20–144 |
| `person_income` | число | Годовой доход | 4 000–6 000 000 |
| `person_home_ownership` | категория | Жильё: RENT, OWN, MORTGAGE, OTHER | - |
| `person_emp_length` | число | Стаж работы, лет | 0–123 |
| `loan_intent` | категория | Цель кредита | - |
| `loan_grade` | категория | Грейд кредита (A-G) | - |
| `loan_amnt` | число | Сумма кредита | 500–35 000 |
| `loan_int_rate` | число | Процентная ставка | 5,42–23,22 |
| `loan_percent_income` | число | Сумма кредита / доход | 0–0,83 |
| `cb_person_default_on_file` | категория | Был ли дефолт в кредитной истории (Y/N) | - |
| `cb_person_cred_hist_length` | число | Длина кредитной истории, лет | 2–30 |

## Модель

Основная модель: **CatBoost** (градиентный бустинг на деревьях).
Baseline: логистическая регрессия.

### Почему CatBoost
- нативно работает с категориальными признаками и пропусками;
- хорошо справляется с табличными данными и нелинейными зависимостями;
- устойчив к выбросам, не требует масштабирования признаков.
