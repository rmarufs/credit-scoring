# Данные

## Источник
Kaggle: Credit Risk Dataset. Ссылка: <вставь ссылку на датасет>.
Файл лежит в `data/raw/` и в git не попадает.

## Назначение
Бинарная классификация: оценка вероятности дефолта по кредиту.

## Размер
32 581 строка, 12 столбцов. Используется весь датасет, без сэмплирования.

## Целевая переменная
`loan_status`: 1 означает дефолт, 0 означает кредит погашен.
Доля дефолтов: около 22% (уточнить в EDA).

## Признаки

| Столбец | Тип | Описание |
|---|---|---|
| `person_age` | число | Возраст заёмщика |
| `person_income` | число | Годовой доход |
| `person_home_ownership` | категория | Жильё: RENT, OWN, MORTGAGE, OTHER |
| `person_emp_length` | число | Стаж работы, лет |
| `loan_intent` | категория | Цель кредита |
| `loan_grade` | категория | Грейд кредита (A-G) |
| `loan_amnt` | число | Сумма кредита |
| `loan_int_rate` | число | Процентная ставка |
| `loan_percent_income` | число | Сумма кредита / доход |
| `cb_person_default_on_file` | категория | Был ли дефолт в кредитной истории (Y/N) |
| `cb_person_cred_hist_length` | число | Длина кредитной истории, лет |

## Известные особенности
- Есть выбросы (например, стаж 123 года в `person_emp_length`).
- Есть пропуски в `person_emp_length` и `loan_int_rate` (проверить в EDA).
- Есть дубликаты (посчитать в EDA).
- `loan_grade` и `loan_int_rate` назначаются банком до выдачи кредита, это нужно учесть при выборе признаков.
- Датасет учебный: метрики на нём могут быть выше, чем на реальных банковских данных.

## Что заполнить после EDA
- Точная доля дефолтов.
- Число пропусков и дубликатов.
- Диапазоны числовых признаков.
